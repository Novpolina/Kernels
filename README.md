# KERNELS: Оптимизация и профилирование вычислительных ядер

Репозиторий содержит реализации оптимизированных вычислительных ядер для матричного умножения (GEMM) и двумерной свертки (Conv2D). Проект ориентирован на минимизацию задержек за счет эффективного использования иерархии памяти и векторных инструкций процессора.

## Реализованные алгоритмы

### 1. Матричное умножение (GEMM)
Реализованы следующие методы вычисления произведения матриц в формате FP32:
* **Naive:** Алгоритм с прямой итерацией по индексам. Обладает низкой эффективностью из-за нелинейного доступа к памяти правой матрицы.
* **Cache-Friendly:** Модификация с предварительным транспонированием правой матрицы для обеспечения последовательного доступа к данным в памяти.
* **Tiled:** Блочное умножение с размером тайла 32x32. Метод оптимизирует использование кэш-памяти L1, локализуя вычисления внутри малых блоков данных.
* **AVX + Tiled + Zero Padding:** Реализация с использованием 256-битных векторных инструкций (AVX). Включает алгоритм дополнения размерностей до кратных восьми для корректной работы векторных регистров.

### 2. Двумерная свертка (Conv2D)
Реализованы методы для тензоров формата CHW:
* **Naive Conv:** Прямое вычисление через шестикратное вложение циклов.
* **Im2Col + AVX GEMM:** Преобразование входного тензора в промежуточную матрицу признаков  с последующим применением оптимизированного ядра AVX GEMM. Поддерживаются параметры `stride` и `padding`.

## Технический стек
* **Язык:** C++17.
* **Компилятор:** GCC / Clang (с флагами `-O3 -march=native`).
* **Библиотека профилирования:** Google Benchmark.

## Сборка и профилирование

Проект использует автоматизированный пайплайн: сборка -> экспорт данных профилирования в JSON -> автоматическая визуализация.

### 1. Сборка проекта
```bash
mkdir build && cd build
cmake -DCMAKE_BUILD_TYPE=Release ..
make -j$(nproc)
```
### 2. Сбор данных (JSON Export)
Результаты экспортируются в JSON:

Bash
```bash
./benchmark_kernels --benchmark_format=json > results.json
```
### 3. Визуализация
Скрипт на Python считывает results.json, парсит значения cpu_time и генерирует графики производительности:
(Выполняется в активированном venv)
```bash
cd ..
python plot_results.py
```
### 4. Анализ производительности
Результаты сохраняются в файл benchmark_results.png.

Графики отражают зависимость времени выполнения от размерности входных данных. Снижение показателей времени в оптимизированных версиях обусловлено увеличением кэш-хитов и использованием параллелизма на уровне инструкций.
